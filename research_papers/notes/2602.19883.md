## Core Problem & Motivation

ODRL’s six set-based operators (`isA`, `isPartOf`, `hasPart`, `isAnyOf`, `isAllOf`, `isNoneOf`) plus `eq`/`neq` **depend on external domain knowledge the W3C spec does not supply**. Without a KB, every cross-dataspace comparison is **Unknown** → default-deny of legitimate sharing.

Four challenges (BSB manuscripts vs French archive):

1. **Single-KB grounding** — GeoNames, BCP 47, DPV turn strings into Compatible / Conflict / Unknown per dimension (France ⪯ Europe; French ⋢ German; DPV R&D vs NonCommercial uncommitted).
2. **Cross-dataspace composition** — conjunction of dimensions; isolate the blocking operand.
3. **Cross-standard alignment** — GeoNames+DPV+BCP 47 vs ISO 3166+GDPR taxonomy+ISO 639-3; unmapped `bavaria` must be Unknown, **never a false Conflict**.
4. **Policy QA** — `and` written for `or` (commercial ∧ academic unsat); redundant France ∧ Europe; DSSC: downstream may only restrict upstream.

**Scope:** constraint-level (can two constraints ever be co-satisfied?), **logically prior** to W3C Formal Semantics rule activation. Complementary to operational evaluators.

## Architecture / Formalism

### Constraint and KB (Defs 1–2)

\(c = (\ell, \triangleright\!\!\triangleleft, v)\).  
\(\mathrm{KB}_\ell = (C, \le, \bot\!\!\bot, \gamma)\): finite concepts; reflexive transitive \(\le\); symmetric irreflexive disjointness **downward-closed**; partial grounding \(\gamma: V \rightharpoonup C\).

Domains (deployment guideline; defs only use \(\le,\bot\!\!\bot\)):

- **Taxonomic** \(\sqsubseteq\): purpose, language, industry, fileFormat, media, recipient
- **Mereological** \(\preceq\): spatial, virtualLocation
- **Nominal** identity: deliveryChannel, device, event, product, system, unitOfCount (`isA` degenerates to `eq`; `isAllOf` requires coincidence)

**Lemma 1:** \(x \le y \Rightarrow \neg(x \bot\!\!\bot y)\).  
**Assumption 1:** KB may be incomplete, never wrong on asserted \(\le\) or \(\bot\!\!\bot\).  
**Assumption 2:** operand independence (justifies per-operand decomposition).

Paper states **14 KB-dependent left operands**; evaluation covers eight operators uniformly. Future work: remaining 11 operands (wording: “extending coverage to the remaining 11 KB-dependent operands”).

### Denotations (Def 3)

If \(\gamma(v)=\bot\), \([[c]]=\top\) (epistemic indeterminate, **not** DL top). Else:

| Operator | Denotation |
|---|---|
| `eq` | \(\{g\}\) |
| `neq` | \(C\setminus\{g\}\) |
| `isA`, `isPartOf` | \(\{x \mid x \le g\}\) (distinction lives in KB \(\le\), **not** the operator label) |
| `hasPart` | \(\{x \mid g \le x\}\) |
| `isAnyOf` | \(\bigcup_i \{x \mid x \le g_i\}\) |
| `isAllOf` | \(\{x \mid \forall i.\ x \le g_i\}\) |
| `isNoneOf` | \(C \setminus \bigcup_i \{x \mid x \le g_i\}\) |

**Conservative intersection (Def 4):** empty wins over \(\top\); else classical ∩; else \(\top\).

**Verdict (Def 5):** Conflict if ⊓ = ∅; Compatible if classical nonempty; Unknown if ⊤.

**Theorem 1 Soundness:** Conflict ⇒ no value satisfies both. Bidirectional denotation rules required: if-direction populates (compatibility); only-if constrains (conflict).

### Composition (Def 6) — Kleene K3

Applied **cross-rule** (e.g. permission vs prohibition refinements), though spec defines `and`/`or`/`xone` as intra-rule.

- **and:** Compatible iff all Compatible; Conflict if any Conflict; else Unknown.
- **or:** Compatible if any Compatible; Conflict iff all Conflict.
- **xone:** Compatible iff **exactly one** Compatible **and all others Conflict**; Conflict iff all Conflict; else Unknown.

**Key finding:** `xone` needs **provable non-overlap** (\(\bot\!\!\bot\), contradictory operators, or structural impossibility). Positive evidence for one branch is **not enough** under open-world → Unknown (ODRL086). Conjunction/disjunction need only positive knowledge.

**Remark 3:** refined exclusivity `excl(B_j,B_k) = verdict_and` of per-operand cross-branch verdicts; orthogonal operands ⇒ vacuous Compatible (cannot prove exclusive). Reduces Unknowns, preserves soundness.

Encoding `xone` directly would need \(\exists\) under negation (breaks **EPR**); composition is therefore **meta-level** over per-branch prover calls.

Supervaluations rejected (quantify over completions); Bochvar too conservative; paraconsistent addresses inconsistency not incompleteness.

### Subsumption (Def 7) and Lemma 2

\(c_1 \sqsubseteq_c c_2\) if \([[c_1]] \subseteq [[c_2]]\) (Confirmed/Refuted/Unknown). Conflict of \(c_2\) with \(c_3\) propagates to refinements of \(c_2\).

### Alignment (Defs 8–9, Prop 2)

Injective partial \(\alpha\) preserving \(\le\) **iff** and \(\bot\!\!\bot\) **one way**, plus **witness completeness** (\(\alpha(g)\neq\bot \Rightarrow {\downarrow}g \subseteq \mathrm{dom}(\alpha)\)). Without it, dropping a common descendant fabricates Conflict (Example 1).

Total / partial / empty alignments. Conflicts preserved; unmapped → Unknown; **never false Conflict** (23/23 alignment tests). KB monotonicity (Prop 3): adding \(\bot\!\!\bot\) or \(\gamma\) never reverses Conflict/Compatible; Unknown may resolve either way.

### Runtime (Defs 10–11, Thm 3)

Execution context \(\omega: L \rightharpoonup V\). Satisfaction requires grounded runtime value **in** denotation (or denotation ⊤—but Conflict cases are grounded). **Default-deny at enforcement** if \(\gamma(\omega(\ell))=\bot\), complementary to Unknown at analysis. Runtime soundness: design-time Conflict ⇒ no \(\omega\) satisfies both.

Isabelle/HOL 2025: 44 results, **0 sorry**, three locales (`knowledge_base`, `kb_extension`, `alignment`). Automated tactics only.

**154 problems**, 19 categories, dual encoding TPTP + SMT-LIB. **Vampire and Z3 agree on all 154.**

KBs (Table 5): GEO000 GeoNames (4), GEO001 ISO 3166 (3), DPV000 (10), DPV001 GDPR-derived (6), LNG000 BCP 47 (10), LNG001 ISO 639-3 (6), NOM000 channels (4); structural CHN000 depth-5, DIA000 diamond, SNG000 singleton (complement collapse ODRL095), NMS000 near-miss.

## Limitations & Failure Modes

- Constraint-level only; **rule activation, duties, refinements-as-W3C, permission/prohibition resolution** are future work.
- Remaining KB-dependent operands not in the 154.
- Operand independence: cannot express “purpose commercial **because** location is US”.
- Incomplete KBs yield Unknown that may hide runtime conflicts (soundness ≠ completeness).
- `isA` and `isPartOf` **identical** given \(\le\); wrong KB type silently mis-evaluates.
- Direct `xone` not in EPR; implementation must keep meta-level composition.
- Open-world **blocks exclusivity** even when “exactly one branch looks satisfied”.
- Singleton domain: `neq` denotation empty (ODRL095).
- Alignment without witness completeness is unsafe.

## Key Takeaways for an NL-to-ODRL system

1. Attach a **typed KB per leftOperand** (taxonomic vs mereological vs nominal) before any conflict check; string equality is not `isPartOf`.
2. Three-valued verdicts: **Unknown is a first-class authoring outcome**, not a failure. Do not coerce to deny at design time; **do** deny at runtime if ungrounded (Thm 3 + Def 11).
3. **Never emit `xone` without disjointness axioms** covering every other branch (or rewrite to `and` of pairwise conflicts).
4. Bidirectional denotation axioms in Z3/Vampire: populate **and** constrain.
5. Cross-dataspace: **order-preserving, witness-complete alignments**; degrade to Unknown.
6. QA checks: unsatisfiable `and`, redundant subsumed conjuncts (`France` ⊑ `Europe`), DSSC downstream-only-restricts via \(\sqsubseteq_c\).
7. Keep SMT in **EPR**; compose `and`/`or`/`xone` outside the solver.
8. Complements Salas normalisation (numeric/symbolic intervals) which **excludes** these set operators.
