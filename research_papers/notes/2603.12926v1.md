- **Source extract:** `research_papers/extracted/2603.12926v1.txt` (17 pages)

## Core Problem & Motivation

ODRL’s expressivity produces (i) **non-interoperable fragments** across tools (some support prohibitions + logical constraints; others only simple permissions) and (ii) **many syntaxes for one meaning**, which makes comparison (containment, equivalence, overlap) combinatorial.

**Gap filled:** parametrised **normalisation** of ODRL Lite policies that:

- rewrites permissions+prohibitions into **permissions only** (prohibition-by-default) or **prohibitions only** (permission-by-default);
- flattens logical constraints to **simple conjunctions**;
- splits numeric intervals so residual simple rules are **pairwise disjoint**;
- reduces comparison to **identity of simple rules**.

Duties, remedies, consequences, set constraints, and `=type`/`isA` are **out of scope**.

## Architecture / Formalism

Semantics inherited from 2509.05139: events, `match`, unique-name assumption, **no semantic reasoning**, constants disjoint.

Constraint taxonomy: simple / numeric / equality / inequality / set / entity / logical / interval. Set comparisons and `=type` **excluded**. ODRL XOR rewritten: \(\lnot c \iff c \oplus (c=0 \lor c\neq 0)\); \(c \oplus d \iff (c\land\lnot d)\lor(d\land\lnot c)\).

### Step 1 — Constraint regularisation \(N(R)\)

1. Conjoin all constraints of \(R\) into one logical constraint.
2. Rewrite operators to \(\{=,<,>\}\) (Table 1, including entity vs numeric variants).
3. Expand to **DNF**.

**Theorem 1:** \(\mathrm{match}(R,e) \iff \mathrm{match}(N(R),e)\).

\(D(R) = \{\bar\tau_1,\ldots\}\) simple rules of the DNF. **Corollary 1:** match iff some \(\tau \in D(R)\) matches.

Example: age/payment XOR becomes two simple permission rules \(R_1, R_2\).

### Step 2 — Interval simplification + splitting \(S(R,V)\)

Conjunctions on one numeric \(\lambda\) collapse to at most two bounds \((\lambda \in (a,b))\), or canonical **false rule** \(R_\bot\) if empty (e.g. \(x>0 \land x<0\)).

**SplitIntervals(\(R_1,R_2\))** (Algorithm 1): for each shared/union left operand \(\lambda\), sort right operands \(V\). If \(R_1\) unconstrained on \(\lambda\), explode “any value” into \((<v)\lor(=v)\lor(>v)\) (numeric) or \((=v)\lor(\neq v)\) (symbolic). If an interval, split at every \(v \in V\) strictly inside \((\rho_{\min},\rho_{\max})\), then re-regularise (line 28, result leaves DNF).

**Theorems 2–3:** splitting preserves match. **Theorem 4:** simple rules after split are **pairwise disjoint**. **Theorem 5 / Corollary 3:** overlap iff shared simple rule; \(R \sqsubseteq R'\) iff \(\dot D(S(N(R),V)) \subseteq \dot D(S(N(R'),V))\) (\(\dot D\) drops empty intervals). Equivalence = set equality of simple rules.

\(NS(\mathcal{R},V) = \bigcup_{R_i} \dot D(S(N(R_i),V))\).

### Permissions vs prohibitions vs obligations

Validity (from 2509): every event permitted; no event prohibited; every obligation matched.

**Theorem 6:** \(\omega\) valid wrt \(\langle P,F,O\rangle\) iff valid wrt \(\langle NS(P,V), NS(F,V), O\rangle\) — **do not split obligations** (splitting an “pay ≥ 10” obligation against value 20 yields *three* obligations, a **stricter** policy).

**Theorem 7 / Corollary 6:** for prohibition-by-default, \(\omega\) valid iff every event matches some \(\tau \in NS(P,V)\setminus NS(F,V)\). Equivalently policy \(\langle NS(P,V)\setminus NS(F,V),\ \emptyset,\ O\rangle\). Dual construction for permission-by-default (subtract permissions from prohibitions).

Worked “carve-out”: permit analyse health data + prohibit pre-2010 → after split, drop the matching P/F pair, keep post-2010 permissions only.

### Complexity (Section 5)

- DNF worst case: CNF of \(n\) atoms that each expand → \(\sim 2^n\) simple rules of size \(n/2\).
- Interval split worst case: unconstrained \(R\) vs \(R'\) with \(L\) attributes and \(|V|\) values → \((2|V|/L + 1)^L\) (exponential in attributes, polynomial in values).
- Set of disjoint rules: \(O(|R|\cdot 2^n)\).

Best case: all equalities, shared left operands — no splits.

**No experimental runtime numbers** (explicitly out of scope). CLI prototype: normalise, split, compare.

## Limitations & Failure Modes

- **Obligations cannot be interval-split** without changing meaning.
- No set operators, no OWL `=type`, no duties/remedies/consequences, no inference/`includedIn`.
- Exponential blow-up in logical width and unconstrained attributes — a generator that emits nested `or`/`xone` can explode the normal form.
- Unique-name + no reasoning: “EU” vs “France” are unrelated symbols unless encoded as numeric/symbolic equalities (conflict-detection paper 2602.19883 is the complementary KB layer).
- Empty-interval rules must be dropped (`\dot D`) or containment proofs fail.
- Prototype unevaluated for scale.

## Key Takeaways for an NL-to-ODRL system

1. After generation, run **N(R) → DNF simple rules → interval split against the comparison partner’s constants**.
2. **Compile prohibitions into permission holes** (or vice versa) so downstream tools that only consume Permissions still get a semantically equal policy.
3. **Never DNF-split obligations.**
4. Comparison of offers vs requests becomes **set inclusion of simple rules** — cheap after normalisation, expensive before.
5. Use \(R_\bot\) as a canonical unsatisfiable rule for empty intervals (feeds SMT “Conflict”).
6. Interoperability pattern: Generator may emit rich logic; **Normaliser** is the contract to evaluators/enforcers with fragment support.
7. Pair with 2602.19883 for taxonomic/mereological operators that this paper refuses to interpret.
